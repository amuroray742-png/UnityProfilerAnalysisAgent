## P0 第一阶段变更

- 新增[独立 dump 解析器](../src-tauri/src/parser/dump.rs)，只保留类型化结构，不构建完整通用 JSON Value 树；按输入结构识别，错误不回退为空 V1。
- 校验重复帧/线程标识、样本索引、时间及树边界；类型错误附数组位置，语义错误附帧、线程、样本和字段信息。
- 主线程由唯一 Main Thread 的唯一根样本确定；录制帧时间独立保存，未知主线程不使用 frame time 或全部 inclusive 耗时替代。
- GC 由所有已导出线程 GC.Alloc metadata 重算，并校验线程及帧总量。站点按线程与最近非 GC.Alloc 父样本归因；无父样本显示未归因。
- 快照数值缺失为 null，附 available / partial / unavailable / estimated、来源、原因与有效帧数。只对有效帧聚合；partial 与 estimated 不产生确定性阈值诊断。
- 删除伪造的 GC 分代次数与 SRP 节省估算；GC 使用明确字节字段，CPU 样本不再被字节 metadata 覆盖。
- JSON 文件读取/解析、data 分块解析以及提取放入阻塞任务。仍需后续验证峰值内存与缓存生命周期，不能承诺容量上限。
- Tauri 命令和参数保持不变，Rust/TypeScript 快照类型同步更新；没有持久化快照迁移。
